# Zotero JournalFlow `v5.1.1`

**Zotero JournalFlow** 是一款专为 **Zotero 10–12**（`Gecko 140+ / 153+`）打造的现代化学术期刊订阅与文献发现插件，基于开源项目 [Lyz-623/JournalLens (`v0.3.9`)](https://github.com/Lyz-623/JournalLens) 按照 **Zotero Flow** 套件工程架构、视觉规范与质量标准全面重构。

---

## `v5.0.0` 全新清新 SVG 图标视觉升级

- **全新清新学术风 SVG 图标体系（`icon.svg` + `toolbar.svg` + 全尺寸 HiDPI PNG）**：
  - 采用晴空蓝、水漾青与薄荷绿的轻盈渐变配色，融合展开期刊双页、半透明纸面高光、左页流动文献流、右页科研光谱折线图卡片、薄荷绿书签丝带以及右上角珊瑚金新知星芒与实时订阅涟漪（`chrome/content/icons/icon.svg`）。
  - 同步定制 `24×24` 极简高对比 `toolbar.svg`（专用于 Zotero 工具栏、菜单项及 `16×16`/`32×32` 小尺寸图标），并重绘全套 `16/32/48/64/96/128px` 高清 PNG 图标。

## `v4.0.0` 大版本工程强化与性能升级

- **SQLite 批量文库 DOI 查重**：将全库遍历替换为按 80 条分批的 `Zotero.DB.queryAsync` `IN (...)` 参数化查询（兼容裸 DOI 与 `doi.org`/`dx.doi.org` 链接变体），大型文库不再卡顿。
- **合并落盘与缓存译文即时检索**：新增 `ReadingStateStore.setReadMany()` 将“全部标为已读”合并为单次磁盘写入；`stampReadingState()` 同步预水合 `_tx` 缓存译文，加载后即可直接检索已翻译内容。
- **图片加载并发去重与域名冷却自动恢复**：同一文献并发触发图片抓取时自动复用进行中任务；图片 CDN 超时黑名单升级为 5 分钟自动过期冷却，避免偶发网络波动后永久无法加载。
- **阅读现场保护与作用域精准批量操作**：后台元数据补全在默认视图下不再重置已展开的摘要；排序方式支持 `sessionStorage` 持久化；**全部翻译**精准限定当前筛选与搜索结果并支持切换作用域时自动中止；快捷键移除卡片前自动顺移焦点；导入 JSON 订阅后自动补全缺失出版社与关联 ISSN。

## `v3.0.0` 大版本升级亮点

- **当前视野概览条与实时工作区指标**：顶部实时展示当前作用域（全部期刊 / 出版社分组 / 单刊与 ISSN）、总篇数 / 未读 / 开放获取 / 星标统计、筛选胶囊动态计数、一键 **全部标为已读**、**重置筛选**、搜索框清空 (`×`) 及悬浮 **返回顶部** 按钮。
- **多维度论文排序**：支持按 *最新发布*、*未读优先*、*含图优先*、*期刊名 A–Z*、*标题 A–Z* 即时切换排序。
- **双语对照阅读与 DOI 一键复制**：译文卡片下方同步保留可对照的 **原文参照** 卡片区，方便核对专业术语；元数据栏新增一键复制 `DOI` 胶囊。
- **增强型大图灯箱（胶片缩略条 + 原图操作）**：支持 `当前/总数` 计数徽标、底部多图缩略胶片条一键跳转、**复制图片链接** 与 **打开原图**。
- **全键盘文献高效筛选流 (`?`)**：支持 `j` / `k` 上下移动卡片焦点、`/` 聚焦搜索、`o` / `Enter` 打开原文、`a` 一键入库、`t` 翻译切换、`s` 星标、`r` 标为已读、`x` 勾选批量入库，随时按 `?` 查看快捷键面板。
- **全新无边框展开期刊 SVG 图标体系**：重构 `icon.svg` 与像素级锐利的 `toolbar.svg` 多尺寸图标集。

## 核心功能

- **Crossref 期刊订阅**：在工作台侧栏按刊名或 ISSN 检索并关注期刊；首次安装默认预置 *Nature*、*Science*、*Cell*，并自动平滑迁移旧版 `extensions.journallens.journals` 订阅列表。
- **双模式工作台**：支持在 Zotero 主界面**内置标签页**或**独立桌面窗口**（`1180×780`）中打开，可在设置面板自由切换，并支持主工具栏按钮、工具菜单以及快捷键 `Ctrl+Alt+J` 一键唤起。
- **近期论文聚合与研究类过滤**：支持配置抓取天数（`1–180` 天，默认 `14` 天）与单刊上限（`10–500` 篇）；结合 Europe PMC 文献类型与标题启发式规则自动过滤新闻、社论、勘误、撤稿等非研究性内容。
- **多源摘要自动补全**：当 Crossref 缺失摘要时，按 Europe PMC（DOI + 标题检索）、Unpaywall 开放获取页面、Meta/JSON-LD 标签及出版商网页正文顺序自动补全。
- **正文大图懒加载与灯箱预览**：滚动时按需提取 Europe PMC `fullTextXML` 与 OA 页面的正文图与 Extended Figure，自动按像素尺寸过滤无效缩略图与封面图标；支持缩放、拖拽平移与键盘快捷键翻页（`←`/`→`/`+`/`-`/`0`/`Esc`）。
- **中英双语智能互译**：支持单篇或批量（3 路并发）翻译标题与摘要，支持 Google 翻译与 MyMemory 互为回退。
- **一键 DOI 入库**：直接调用 Zotero 原生 `Translate.Search` 将目标文献快速保存至本地文库。
- **独立文件每日缓存**：使用现代 `IOUtils` / `PathUtils` 将每日缓存持久化到 `<ZoteroDataDir>/journalflow-cache.json`，彻底告别旧版把海量 JSON 写入 `prefs.js` 的隐患。
